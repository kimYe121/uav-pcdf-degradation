# PCDF 复现审计（2026-11-25）

只回答一个问题：为什么本实现 stage2 只比 baseline 高 0.4 点，而论文是 +4.7。

## 结论

**主因是阶段 2 的引导协议错了，而不是几何、不是算力。**

论文的 `L_dt`（式 6，Sec 4.3）目的是把**文本条件引导**蒸馏进 `F_s`，使测试时可以用
`GAP(F_s)` 替换文本：如果阶段 2 训练时 CDF 本来就由 `F_t` 驱动，这条损失才有存在意义；
测试阶段 SCPL 关闭（Sec 4.2 "SCPL is only utilized in training"），CDF 才切换到 `F_s`。
补充材料 Fig. 10 的 Stage II 也画了 SCPL → CDF 的箭头。

本实现阶段 2 从第 0 轮起就把 CDF 的引导换成 `GAP(F_s)`，而此时 PCD 三支（V/S）是**随机
初始化**的。CDF 学到的是"忽略引导、只看池化特征"，等 S 学会条件语义时已经晚了。

## 证据（stage2 last.pt，test 1503 张；探针脚本 `scripts/probe_cdf.py`）

| 现象 | 数值 | 含义 |
|---|---|---|
| 打乱引导向量 `F_s` | 56.49 → 56.28（−0.21） | 条件引导几乎没被使用 |
| 权重取自另一张图 | 0.52 | 逐图权重是命脉（内容驱动），不是噪声 |
| `W_ir` 按条件分组 | night 0.541 vs sunny 0.498（Δ0.04） | 条件维度几乎不动 |
| 引导对 `W` 的贡献 | 打乱引导 \|ΔW\|=0.032 vs 打乱池化 0.057 | 投影输入里内容占主导 |
| 文本 vs 视觉引导 | 逐样本余弦 −0.11 | CMD 只对齐 batch 边缘矩，样本不配对 |
| SCPL 门控 | 保留 1.94/6；illumination 概率 0.015 | 光照（最该用的线索）几乎总被丢 |

## 与论文的逐项对照

| 项 | 论文 | 本实现（改前） | 判定 |
|---|---|---|---|
| 阶段 2 CDF 引导 | 文本 `F_t`（Fig.10 Stage II；L_dt 的存在前提） | `GAP(F_s)`（随机初始化） | **错**，主因 |
| CDF 输入 | 引导 + 两模态特征（Fig.4 三路箭头） | 同 | 对 |
| CDF 权重 | 逐通道 softmax，作用于 `F_v`（式 10-11） | 同 | 对 |
| `L_dt` | CMD（式 6） | 同（batch 边缘矩） | 对，但对齐弱 |
| `L_irr` | `‖F_vᵀF_s‖_F²`（式 7） | 除以像素数归一 | 量级不同，贡献 ~0.004 |
| `L_dc` | 作用于 `F_v`（式 8） | 作用于加权后的 `W⊙F_v`（Fig.4 读法） | 可能偏差 |
| 阶段 1 | 只训 SCPL+CDF，主干冻结 | 同 | 对 |
| 测试 | 无文本、无 SCPL、`GAP(F_s)` | 同 | 对 |

## 修复与实验顺序

1. **阶段 2 训练：文本引导 + `fuse="decoupled"`**（已实现：`pcdf.forward(fuse=...)`，
   `train._step` 阶段 2 传 `fuse="decoupled"`）。测试仍走视觉引导。
2. 在同一原生几何下重跑 stage1 → stage2，测试时同时评 `--guidance visual`（部署）
   与 `--guidance text --fuse decoupled`（上限）。判据：
   - 视觉 ≈ 文本且 > 56.5：修复成立；
   - 视觉 ≪ 文本：`L_dt` 对齐不足，下一步加逐样本对齐项（cosine+MSE）或把 CMD 改为
     逐样本通道矩，再重跑 stage2。
3. 若仍不足，再试补充材料 B.3 的另一种读法：阶段 2 只训 PCD、冻结 CDF（保留阶段 1 的
   条件先验）；这是备选，不与第 1 步混跑。
